**Change 2 — Wire integrity check into executeImport() success path.**

Find the `executeImport()` method (around line 251). The success path ends with:
```js
notificationUI.success('Import successful! The app will now reload.');
window.location.reload();
```

The page reloads immediately, so a fire-and-forget `.then()` after the reload would never execute. Instead, call `validateDataIntegrity()` synchronously (with `await`) before the success toast and reload, inside the existing try block. If issues are found, show a warning toast with a cleanup action, then reload. If no issues, proceed as before.

Replace the success path inside the try block with:
```js
await importBackupData(data, {
  mode: _pendingImportMode,
  restoreSettings: _pendingImportMode === 'overwrite'
});

// Phase 27: Check integrity immediately after import, before page reload
const { valid: importValid, issues: importIssues } = await validateDataIntegrity();
if (!importValid) {
  let resolveCleanup;
  const cleanupDone = new Promise(resolve => {
    resolveCleanup = resolve;
  });

  notificationUI.warning(
    `⚠️ ${importIssues.length} data integrity issue${importIssues.length !== 1 ? 's' : ''} found in imported data.`,
    [
      {
        label: 'Clean up',
        onClick: async () => {
          await cleanOrphanedRecords(importIssues);
          notificationUI.success('Orphaned records removed.');
          resolveCleanup();
        },
      },
    ],
    8000
  );

  // Keep reload unconditional, but defer it until cleanup completes or warning window closes.
  await Promise.race([
    cleanupDone,
    new Promise(resolve => setTimeout(resolve, 8000)),
  ]);
}

notificationUI.success('Import successful! The app will now reload.');
window.location.reload();
```

This keeps the reload unconditional (the import succeeded) while deferring it until either cleanup completes or the warning timeout expires.
