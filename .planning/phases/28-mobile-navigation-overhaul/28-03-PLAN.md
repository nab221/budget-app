<objective>
Make `.month-nav` (the pay-period / month picker) sticky on mobile so it stays visible below the sticky header when content is scrolled.

Purpose: The verification report found that both MOB-02 and NAV-02 are unmet because `.month-nav` has only static positioning. The sticky header (z-index: 100, added in Plan 28-01) holds the top of the screen but the month picker scrolls away. Adding one CSS rule inside the 768px media query closes both gaps simultaneously.
Output: An updated `css/main.css` where `.month-nav` is sticky on mobile at the correct offset below the header, with a `--header-height` variable that makes the offset maintainable.
</objective>

<task type="auto">
  <name>Task 1: Add --header-height variable and sticky .month-nav rule to the 768px media query</name>
  <files>css/main.css</files>
  <action>
Read `css/main.css` before making any changes.

Make two targeted edits inside the existing `@media (max-width: 768px)` block (the one that opens around line 220):

**Edit 1 — Add `--header-height` to the `:root` block inside the 768px query.**

The `:root` block inside the 768px query currently reads:
```css
:root {
  --bottom-bar-height: 72px;
}
```

Add `--header-height: 56px;` to that block so it becomes:
```css
:root {
  --bottom-bar-height: 72px;
  --header-height: 56px;
}
```

56px is the correct mobile value: the header renders as a single flex row with 1.5rem h1 text, 10px gap, and the 14px shell padding. Do NOT add a separate `:root` block — append to the existing one.

**Edit 2 — Add a `.month-nav` sticky rule at the end of the 768px block**, immediately before the closing `}` of that media query:

```css
  .month-nav {
    position: sticky;
    top: var(--header-height);
    z-index: 99;
    background: var(--bg-alt);
  }
```

This places `.month-nav` directly below the sticky header (z-index 100) without overlapping it. The `background: var(--bg-alt)` prevents page content from bleeding through the picker while it is in sticky position.

**Do NOT:**
- Change the global `.month-nav` rule (lines ~493–501 outside all media queries) — it handles desktop layout and must be left alone.
- Change any other rules inside or outside the 768px block.
- Add a new `:root` block — edit the existing one.
