### Task 23.1.3: Dirty-State Tracking ✅

**File:** `src/ui/cloud-sync.js`  
**Methods Added:**
- `_initDirtyStateTracking()` - Initialize on app load
- Stores dirty state in localStorage key `budget_cloud_is_dirty`

**Implementation:**
1. Load `_isDirty` from localStorage on init
2. Listen to Dexie `db.on('mutated')` event
3. On mutation: Set `_isDirty = true` and save to localStorage
4. On successful push: Clear `_isDirty = false`
5. Persist state across page reloads

### Task 23.1.5: Last Synced Timestamp ✅

**File:** `src/ui/cloud-sync.js`  
**Methods Added:**
- `_formatLastSynced(timestamp)` - Format as relative time
- `_updateTimestampDisplay()` - Update DOM element

**Relative Time Format:**
- < 1 min: "Just now"
- < 60 min: "5m ago"
- < 24 hours: "3h ago"
- 1 day: "Yesterday"
- < 7 days: "2d ago"
- Older: "2/15/2026"
