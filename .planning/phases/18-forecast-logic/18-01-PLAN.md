<feature>
  <name>Daily Balance Forecast Engine</name>
  <files>src/utils/cashflow.js, src/utils/cashflow.test.js</files>
  <behavior>
    The engine should calculate daily snapshots for 90 days.
    Each snapshot contains: { date, openingBalance, closingBalance, incomeTotal, expenseTotal }.
    
    Formula: closing = opening + income - expenses.
    
    Recurrent Expense Adjustment:
    - If a recurrent expense falls on a weekend or bank holiday, its effective date for the forecast moves to the NEXT working day.
    - One-off expenses remain on their entry date.
    
    Test Cases:
    - Normal weekday: recurrent expense stays on its date.
    - Weekend (Saturday): recurrent expense moves to Monday.
    - Bank Holiday (e.g. Easter Monday): recurrent expense moves to Tuesday.
    - 90-day span: exactly 90 records produced.
    - Opening balance: inherited from previous day's closing.
  </behavior>
  <implementation>
    1. Fetch all relevant records for the 90-day horizon from startDate.
    2. Initialize daily snapshots array.
    3. Loop from 0 to 89 (for 90 days):
       a. Current date = startDate + i days.
       b. Opening balance = i=0 ? (fetched from latest snapshot) : previous closing.
       c. Sum income for "today".
       d. Sum one-off expenses for "today".
       e. For each recurrent expense:
          i. If nextDate is in horizon, calculate its effective date using `nextWorkingDay`.
          ii. If effective date === "today", add to expenses.
       f. closing = opening + income - expenses.
       g. Push to snapshots array.
    4. Return or bulk-save snapshots.
  </implementation>
</feature>
