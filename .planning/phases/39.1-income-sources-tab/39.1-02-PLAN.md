    **Lookback calculation:**
    ```javascript
    function lookbackDate() {
      const d = new Date();
      d.setDate(d.getDate() - 45);
      return d.toISOString().split('T')[0];
    }

    function oneWeekAhead() {
      const d = new Date();
      d.setDate(d.getDate() + 7);
      return d.toISOString().split('T')[0];
    }
    ```

    **In render():**
    ```javascript
    const activeSources = await incomeSourceRepository.getActive();
    const upcoming = getUpcomingIncomeEvents(activeSources, lookbackDate(), 10)
      .filter(ev => ev.adjustedDate <= oneWeekAhead());
    ```

    **CRITICAL pence/pounds pitfall (from RESEARCH.md Pitfall 1):**
    - event.amount from getUpcomingIncomeEvents is in PENCE
    - incomeRepository.add() calls toPence() internally, so amount must be passed in POUNDS
    - Correct: `amount: fromPence(event.amount)` — this gives pounds float, which repo converts back to pence
    - Wrong: `amount: event.amount` — this would store the value 100x too large

    **For adjust flow:**
