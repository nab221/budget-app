# Phase 14-02: Functional UI Refinement and Entry Management

This phase moves all entry forms into modals and unifies the dashboard balance panel.

## Goals
- Address visual "tightness" in entry forms by moving them into modals.
- Reorder and unify the dashboard balance panel.
- Implement dynamic font scaling for dashboard cards.

## Tasks
1. **Dashboard Refinement**:
   - Update `src/ui/dashboard.js` to render three cards: Running Balance → Next Month Forecast → 3-Month Forecast.
   - Use identical visual style for all three cards.
   - Hide cards with missing data.
   - Implement `adjustFontSize` for dashboard cards using `formatGBPShort`.
2. **Modal Migration**:
   - Update `src/ui/income.js`, `src/ui/expenses.js`, `src/ui/assets.js`, `src/ui/debts.js` to use modals for adding entries.
   - Remove inline forms from `index.html`.
   - Add "+ Add" buttons to trigger modals.
3. **Table Cleanup**:
   - Identify and remove any "banner-style" layout (where values appear above headings in tables).
   - Verify dynamic row height across all tabs.

## Verification
- [ ] Dashboard balance panel shows 3 cards in the correct order.
- [ ] Large currency values in dashboard cards scale down font size.
- [ ] Adding income/expenses/assets/debts triggers a modal.
- [ ] Inline forms are removed from `index.html`.
- [ ] Long text in tables wraps correctly.
