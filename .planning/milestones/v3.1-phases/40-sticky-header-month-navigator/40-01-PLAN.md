```css
header::before {
  content: '';
  position: absolute;
  top: 0;
  bottom: 0;
```

<task type="auto">
  <name>Task 2: JS — ResizeObserver, scroll listener, tab-switch scroll reset in app.js</name>
  <files>src/app.js</files>
  <action>
Make two targeted edits to src/app.js:

**Edit 1 — Add ResizeObserver and scroll listener after the `await Promise.all(...)` block:**

Find the line `refreshPersistenceWarning()` which is the last item inside the `await Promise.all([...])` block (around line 116). After the closing `]);` of that block, and before the `// 1. Define Global App Object` comment, add:

```javascript
// Dynamic header height — keeps --header-height accurate when cloud-sync injects buttons
const _headerEl = document.querySelector('header');
if (_headerEl) {
  new ResizeObserver(entries => {
    const h = Math.round(entries[0].contentRect.height);
    document.documentElement.style.setProperty('--header-height', `${h}px`);
  }).observe(_headerEl);
}

// Scroll shadow — adds/removes .scrolled class on header as user scrolls
window.addEventListener('scroll', () => {
  document.querySelector('header')
    ?.classList.toggle('scrolled', window.scrollY > 0);
}, { passive: true });
```

Use `{ passive: true }` on the scroll listener — this prevents scroll thread blocking in Chrome (without it, Chrome logs a "violation" warning).

**Edit 2 — Add scroll reset to tab click handler:**

Find the `mainTabs.addEventListener('click', async (e) => {` handler (around line 172). Inside it, find the line `await window.app.renderAll();` (the last statement before the closing `});`). Add these two lines immediately BEFORE the `await window.app.renderAll()` call:

```javascript
window.scrollTo({ top: 0, behavior: 'instant' });
document.querySelector('header')?.classList.remove('scrolled');
```

Use `behavior: 'instant'` (not `'smooth'`) — smooth scroll during a tab switch produces a jarring visible animation while the tab content has already changed. Removing `.scrolled` explicitly here prevents a brief shadow flicker on the freshly-switched tab before the passive scroll listener fires.
