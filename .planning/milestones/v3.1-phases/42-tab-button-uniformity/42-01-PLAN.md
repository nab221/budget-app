<objective>
Fix tab button CSS so all 8 mobile bottom-nav buttons are pixel-identical in height and shape whether active or inactive.

Purpose: The mobile `.tab.active` rule only overrides `background` and `color`. The desktop rule's `box-shadow`, `border-radius` (via `999px`), `font-weight: 600`, and `transition: all` all leak through the cascade, causing the active tab to momentarily change shape and size on tap.

Output: Updated `css/main.css` — the mobile `.tab.active` block (lines 285–288) is expanded with a full reset, a `.tab:active` rule is added to suppress UA transform, and `transition: color` replaces the inherited `transition: all` on the mobile `.tab` rule. No JS, no HTML changes.
</objective>

The mobile `.tab` rule does not currently override `transition`. Add `transition: color var(--tr)` as the last property inside that block (before the closing `}`). This prevents the inherited `transition: all` from animating shape-affecting properties during tap.

The result should look like:
```css

    flex: 1 1 0;
```
