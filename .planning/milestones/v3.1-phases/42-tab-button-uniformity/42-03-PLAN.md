The rule must become:
```css
.tabs {
  display: flex;
  justify-content: space-around;
  padding: 8px 0;
  gap: 0;
  overflow: hidden;
  width: 100%;      /* Pin container to parent — prevents intrinsic growth when active tab changes */
  max-width: 100%;  /* Belt-and-suspenders: prevent overflow on any layout edge case */
}
```

No other rules change. Do NOT touch `.tab`, `.tab.active`, `.tab:active`, or any rule outside this block.
