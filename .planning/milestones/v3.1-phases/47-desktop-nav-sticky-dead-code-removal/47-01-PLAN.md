```css
.nav-container {
  position: relative;

}
```

Replace it with:

```css
.nav-container {
  position: sticky;
  top: var(--header-height, 56px);
  z-index: 99;
  background: var(--bg);
  margin-bottom: 14px;
}
```

Rationale:
- `position: sticky` keeps the nav visible when the user scrolls past it on desktop
- `top: var(--header-height, 56px)` pins it immediately below the sticky header — the variable is updated at runtime by the Phase 40 ResizeObserver in app.js; the 56px fallback matches the :root default
- `z-index: 99` is one below the header's z-index: 100, ensuring the header always renders on top when they overlap at the boundary
- `background: var(--bg)` prevents page content from bleeding through the nav bar as it sticks
- `margin-bottom: 14px` is preserved unchanged

Do NOT touch the `@media (max-width: 768px)` `.nav-container` rule — mobile uses `position: fixed` and must not be changed.
