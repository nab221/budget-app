**TRANS-08 — Define handleCategoryChange and clearCategoryFilter on transactionUI:**

In `src/ui/transactions.js`, add two methods to the `transactionUI` object. Place them near the other utility methods, after `clearCategoryFilter` would logically live — a good location is just before `renderCategoryFilter` (around line 403), but any location inside the `transactionUI` object literal is acceptable as long as both methods are defined as properties of `transactionUI`.

```javascript
  handleCategoryChange(checkbox) {
    const catId = checkbox.value;
    if (checkbox.checked) {
      if (!this.selectedCategories.includes(catId)) {
        this.selectedCategories = [...this.selectedCategories, catId];
      }
    } else {
      this.selectedCategories = this.selectedCategories.filter(id => id !== catId);
    }
    this.render();
  },

  clearCategoryFilter() {
    this.selectedCategories = [];
    this.render();
  },
```

These two methods satisfy the onchange/onclick handlers already in the `renderCategoryFilter` template at lines 421 and 427. No changes to `renderCategoryFilter` itself are needed — the template already calls the correct method names, uses `allCats` (not `incomeCats`), and the `filterTransactions` wiring in `renderTransactions` is already correct.

Do NOT change `renderCategoryFilter`, `renderTransactions`, or any other method beyond what is specified above.
