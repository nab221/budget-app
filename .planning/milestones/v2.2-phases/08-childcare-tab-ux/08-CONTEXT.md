# Phase 8 Context: Childcare Tab UX

## User Decisions
- **Opening Balance**: Add "Opening Balance (£)" field to childcare account form. Ledger running total MUST start from this value. (Locked)
- **Click-to-open**: Clicking a childcare account card MUST open the ledger view for that account. (Locked)
- **Edit Button**: Add an "Edit" button to the card header OR the bottom of the ledger. (Locked)

## Success Criteria
- [ ] Childcare card click opens ledger view inline.
- [ ] Opening balance field correctly initializes the running total in the ledger.
- [ ] Edit functionality is easily accessible from the ledger view.

- CHILD-01: Clicking childcare card opens ledger view for that account.
