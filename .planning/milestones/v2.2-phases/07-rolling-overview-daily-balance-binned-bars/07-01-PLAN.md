# Phase 7 Plan: Rolling Overview - Daily Balance & Binned Bars

Refine the "Rolling Financial Overview" chart to support mixed-resolution data: a high-resolution daily line for Account Balance overlaying summarized (weekly or monthly) bar charts for Income and Expenses.

## 1. UI Updates (`src/ui/dashboard.js`)
- [ ] Change default `_selectedBinning` to `'W'` (Weekly).
- [ ] Update `renderBinningSelector` to remove the 'Daily' (D) option.
- [ ] Ensure the UI only displays 'W' and 'M' in the segmented control.

## 2. Data Logic Refactor (`src/utils/cashflow.js`)
- [ ] Refactor `aggregateRollingOverview` to support mixed-resolution output:
    - Keep the high-resolution daily `labels` and `balance` data.
    - Group daily income/expenses into bins (Weekly/Monthly).
    - Map each daily index to its corresponding bin total.
    - Data structure for income/expenses: `Array<{ y: number, daily: number, isForecast: boolean }>`.
    - `isForecast` is true if any date in the bin is after "Today".
- [ ] Ensure `date-fns` is used for consistent binning (Monday-anchored weeks).

## 3. Chart Rendering Refactor (`src/ui/charts.js`)
- [ ] Implement `barForecastPlugin`:
    - Hook into `afterDatasetsDraw`.
    - Apply `ctx.setLineDash([4, 4])` and `ctx.strokeRect` for bars where `isForecast` is true.
- [ ] Register `barForecastPlugin` with Chart.js.
- [ ] Update `renderRollingOverviewChart`:
    - **Datasets**:
        - `Account Balance` line: Daily resolution, `order: 1` (on top), black color.
        - `Income` & `Expenses` bars: Binned resolution, `order: 2`.
        - Set `barPercentage: 1.0` and `categoryPercentage: 1.0` for seamless bars.
        - Use scriptable properties for `backgroundColor`: 0.5 opacity for forecast bins.
    - **Scales**:
        - X-axis: Filter ticks to show labels only on Mondays (Weekly) or 1st of Month (Monthly).
        - Y-axis: Keep existing currency formatting.
    - **Tooltips**:
        - Custom callback to show both the **Bin Total** (Weekly/Monthly) and the **Daily Activity** for that specific day.
        - Use absolute values for labels (no negative expenses in UI).
