# Milestone v2.7: Cloud-First Sync & UX Refinement

## Core Goals
Prioritize Supabase cloud storage over local files, implement auto-sync on exit, and improve onboarding/auth flows.

---

## UX Requirements

### SYNC-UX-01: Consolidated Top-Bar Actions
- **Condition:** If `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY` are configured.
- **Action:** Replace local **"⬆ Import / ⬇ Export"** with Cloud Sync actions.
- **Actions:** 
  - **"☁ Sync Pull"**: Download latest cloud snapshot.
  - **"☁ Sync Push"**: Upload current local database to cloud.
- **Auth State:** 
  - If signed out: Show **"☁ Sign In"** button (re-routes or opens modal for email entry).
  - If signed in: Show Push/Pull buttons.

### SYNC-UX-02: Dirty State Indicator
- **Goal:** Visually communicate that local data has unsynced changes.
- **Action:** Add a small dot or text label next to the "Sync Push" button that appears whenever a write operation occurs in Dexie.
- **Reset:** Indicator clears only after a successful cloud push.

---

## Sync Behavior Requirements

### SYNC-BEH-01: Auto-Pull Prompt on App Load
- **Action:** On initialization, compare the local `budget_cloud_last_sync` timestamp with the `updated_at` timestamp from the cloud snapshot.
- **Condition:** If cloud is newer, show a non-intrusive notification or modal prompt: *"Newer cloud data found. Pull now?"*

### SYNC-BEH-02: Auto-Push on Visibility Change
- **Goal:** Minimize data loss by syncing when the user leaves the app.
- **Trigger:** Listen for `visibilitychange` event.
- **Action:** If `document.visibilityState === 'hidden'` and the state is "Dirty", trigger a background `pushSnapshot`.

### SYNC-BEH-03: Post-Auth Auto-Pull
- **Action:** Upon successful email sign-in (magic link completion), automatically trigger a `pullSnapshot` (with preview) to help new users get their data immediately.

---

## Error Handling Requirements

### SYNC-ERR-01: Sync Failure Notifications
- **Condition:** Background push fails (e.g., no internet).
- **Action:** Notify the user with a subtle toast or banner: *"Cloud sync failed. Save a local backup to stay safe?"*
- **Action:** Show the legacy local Export button temporarily as a fallback.

---

## Non-Functional Requirements
- **Performance:** Background sync should not block the main UI thread.
- **Stability:** Sync operations must handle network timeouts gracefully.
- **Audit:** All sync events should be logged to the console for debugging.
