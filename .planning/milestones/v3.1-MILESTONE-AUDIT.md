**Total: 6 items across 4 phases. No blockers.**

### Phase 41 — Bottom Nav (1 item)

- **TODO-NAV-02:** Mobile nav jank on Transactions and Payoff tabs on real devices. Root cause: Chart.js canvas + swipe-gesture compositing. Accepted by user. Future phase.
  *(Note: TODO-NAV-01 desktop nav not sticky was resolved by Phase 47 — DESK-01 satisfied.)*

### Phase 45 — Transactions (1 item)

- **app:refresh listener proliferation:** Three modules register `app:refresh` listeners. Phase 48 fixed double-render on the `toggleExpenseStatus` hot path by replacing the dispatch with direct calls. But the listeners themselves remain and fire on any other `app:refresh` dispatch (settings save, etc.). Idempotent renders — correct but architecturally wasteful.

### Phase 49 — Legacy Buttons (1 item)

- **Dead handler code:** `expenses.js` lines 169–190 — `getElementById` lookups for `#markAllPaidBtn` and `#triggerRecurrenceBtn` that permanently return `null` after Phase 49 removal. Wrapped in `if` guards; zero runtime impact. Cleanup candidate.
