# Phase 29-01 PLAN: UI Form Updates

## Goal
Implement "Recurring" toggle and "Frequency" dropdowns in `src/ui/expenses.js` for both Recurrent and One-off forms. Update the save logic to generate the first 12 instances of a new recurring series.

## Requirements Traceability
- [x] **RECURRENCE-UI-01**: Add "Recurring" checkbox to both forms.
- [x] **RECURRENCE-UI-02**: Add "Frequency" dropdown to both forms.
- [x] **RECURRENCE-GEN-01**: Trigger 12-month generation on initial save of a recurring item.
- [x] **RECURRENCE-UI-03**: Add 🔁 icon to table rows for recurring items.

## Implementation Steps

### 1. Update `renderForm()` in `src/ui/expenses.js`
- **Recurrent Form**:
    - Add `<input type="checkbox" id="expIsRecurring">`.
    - Ensure `Frequency` dropdown handles `weekly`, `biweekly`, `monthly`, `quarterly`, `annually`.
    - Note: `annual` was used in `src/ui/expenses.js` but `annually` is the requirement. I should check which one is used in `recurrence.js`.
    - `recurrence.js` uses `annually`. I'll update the form to match.
- **One-off Form**:
    - Add `<input type="checkbox" id="expIsRecurring" onchange="expensesUI.toggleFrequencyField()">`.
    - Add `<select id="expFreq" disabled>`.
    - Implement `toggleFrequencyField()` to enable/disable the dropdown.

### 2. Update `handleSaveExpense()` in `src/ui/expenses.js`
- **Extract new fields**: `isRecurring` and `frequency`.
- **Logic for New Recurring Item**:
    - After `await repository.add(payload)`, if `isRecurring` is true:
        - Get the saved item (to have its ID and any defaults).
        - Call `generateInstances(savedItem, frequency, 12)`.
        - Use `repository.bulkAdd(instances)` to save the next 12.
        - Ensure `triggerBalanceRecalc` is called for the last instance's date (this might be overkill but ensures the chain is complete).

### 3. Update Table Rendering in `src/ui/expenses.js`
- **`renderRecurrent()`**:
    - Add 🔁 icon next to the label if `item.isRecurring`.
- **`renderOneOff()`**:
    - Add 🔁 icon next to the note if `item.isRecurring`.

### 4. Verification Plan
- **Test Case 1**: Add a new recurring Recurrent Expense (e.g. "Rent", Monthly).
    - [ ] Verify first record saved.
    - [ ] Verify 12 future records appear in subsequent months.
    - [ ] Verify 🔁 icon is present.
- **Test Case 2**: Add a new recurring One-off Expense (e.g. "Gym", Weekly).
    - [ ] Verify 12 future records appear (weekly).
    - [ ] Verify 🔁 icon is present.
- **Test Case 3**: Add a non-recurring One-off Expense.
    - [ ] Verify only one record saved.
    - [ ] Verify no 🔁 icon.
