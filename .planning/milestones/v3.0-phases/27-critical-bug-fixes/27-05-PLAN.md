<objective>
Remove the prior-year heatmap rendering from all four call sites. The selected year's heatmap is the only one that should render — no "Prior Year" label, no second canvas, no cross-year data fetch.

Purpose: When the user navigates to a previous year and adds income, the heatmap currently renders two canvases: the target year (partially visible, cannot scroll) and a redundant "Prior Year" canvas. This is confusing and partially hides content. The fix is surgical: remove the prior-year fetch, remove the `allData` merge, remove the `hasPrevYearData` conditional block, and simplify each `renderSpendingHeatmap` call to pass no `allYearsData`.

Output: Three modified files. No new files. No changes to heatmap.js.
</objective>
