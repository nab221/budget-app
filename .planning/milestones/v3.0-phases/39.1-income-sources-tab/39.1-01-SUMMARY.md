## Decisions Made
- **Stub module required:** Vite's import-analysis plugin resolves module paths during transform, before vi.mock hoisting takes effect. The `vi.mock('../src/ui/income-sources.js', factory)` call is hoisted but the path still needs to resolve to a real file. Solution: create `src/ui/income-sources.js` as a no-op stub. Tests still go RED because they assert repository side-effects that stub methods do not produce.
- **Test structure — UI method calls, not direct repo calls:** Initial attempt had tests calling `incomeSourceRepository.validateAndAdd()` directly in test bodies, which trivially passed. Restructured so tests call `incomeSources._handleAddSource()` etc., which the no-op stub ignores — producing correct RED failures.
