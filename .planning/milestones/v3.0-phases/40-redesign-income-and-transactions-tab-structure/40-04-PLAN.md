From src/ui/transactions.js — _initSwipe() (lines 632–731):
The current swipe setup iterates all .swipe-row elements in the table body.
For expense rows it checks `if (rowType === 'expense' && row.querySelector('[data-tab="debts"]')) return;`
— this attempts to detect debt rows by looking for a child element with data-tab="debts", but that
  attribute appears on the `onclick` string, not on a DOM child element. This guard fires incorrectly
  for ALL expense rows, skipping swipe setup entirely.

Correct approach: detect debt rows via `row.dataset.isDebt === 'true'` OR by checking for absence
of `.btn-edit` inside the row (debt rows have no edit button). The rendered HTML already sets
`data-row-type="expense"` but does NOT set `data-is-debt`. The isDebt flag is on the rendered `<tr>`:
  - Non-debt expense: has `.btn-edit` button rendered in `col-actions` td
  - Debt-linked expense: no `.btn-edit`, only a navigation onclick on the tr

Fix: replace the bad guard with: `const isDebtRow = rowType === 'expense' && !row.querySelector('.btn-edit');`

From src/ui/transactions.js — income row onclick (lines 721–728):
Current income row click handler only closes the open swipe row:
```js
row.onclick = (e) => {
  if (this.currentOpenRow === row) {
    if (!e.target.classList.contains('swipe-action-left') && !e.target.classList.contains('swipe-action-right')) {
      this.closeAllRows();
    }
  }
};
```
This does NOT navigate to the Income tab. The fix: after closing the row, if the row is NOT currently
open as a swipe row AND the click target is not an action button, navigate to income-sources tab:
```js
row.onclick = (e) => {
  if (this.currentOpenRow === row) {
    if (!e.target.classList.contains('swipe-action-left') && !e.target.classList.contains('swipe-action-right')) {
      this.closeAllRows();
    }
    return; // was open — just close, don't navigate
  }
  // Tap on a closed income row → navigate to Income tab
  if (!e.target.classList.contains('btn-edit') && !e.target.classList.contains('btn-delete')) {
    const incomeTab = document.querySelector('[data-tab="income-sources"]');
    if (incomeTab) incomeTab.click();
  }
};
```

From index.html — Income tab nav button:
```html
<button class="tab" data-tab="income-sources" aria-label="Income">
  <span class="tab-label">Income</span>
</button>
```
Selector: `document.querySelector('[data-tab="income-sources"]')`

From src/ui/expenses.js — global expense CRUD:
- `window.expensesUI.editExpense(id, type)` — opens edit modal for a recurrent or oneOff expense
- `window.deleteExpense(id, type)` — confirms and deletes the expense, triggers app:refresh
Both are set as globals on window by expenses.js init. Use optional chaining for safety.
