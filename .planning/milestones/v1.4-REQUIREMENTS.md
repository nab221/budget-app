# v1.4: Local File Persistence with File System Access API - Requirements

This milestone enables users to sync their IndexedDB budget data with a local file on their computer, ensuring persistent storage outside the browser and enabling easy backups or sharing.

## Requirements

### REPO: Repository Refactoring
- **REPO-01**: Consolidate all database writes/mutations to `src/db/repository.js`.
- **REPO-02**: Remove all inline Dexie `db.table.add/put/delete` calls from `budget-app.html` and move to repository.
- **REPO-03**: Implement a middleware or hook in the repository to trigger sync on every mutation.

### FS: File System Handle Management
- **FS-01**: Implement `src/utils/storage.js` utility for picking a file handle.
- **FS-02**: Persist the picked file handle in IndexedDB (using `idb-keyval` or similar).
- **FS-03**: Implement `requestPermission` and `queryPermission` logic for persisted handles.
- **FS-04**: Verify handle validity on app load and provide re-authorization flow.

### SYNC: Auto-save & Sync Logic
- **SYNC-01**: Implement periodic/triggered export of full database to the selected file handle.
- **SYNC-02**: Add a debounce (e.g., 2-5 seconds) to mutation-triggered saves to prevent excessive writes.
- **SYNC-03**: Implement resilience logic for cloud-synced folders (OneDrive/Dropbox) to handle `NoModificationAllowedError` with retries.
- **SYNC-04**: Ensure atomic-like writes using `createWritable` swap file mechanism.

### UI: File Persistence UX
- **UI-01**: Add a "Local File Sync" section in the settings/backup UI.
- **UI-02**: Button to "Select Local File" and initialize sync.
- **UI-03**: Visual indicator of sync status (Synced, Saving, Error, Unauthorized).
- **UI-04**: "Re-connect" button for handles that lost permission.

### DOCS: Documentation & Validation
- **DOCS-01**: Update README with instructions for the new File System Access feature.
- **DOCS-02**: Document browser compatibility and PWA persistent permission caveats.
- **VAL-01**: Validate that data persists after browser restart and handle re-authorization.
- **VAL-02**: Verify no regression in existing GDrive/OneDrive cloud backup.
