# Milestone v2.1 Requirements: Advanced Refinements & Security (ARCHIVED)

**Status:** COMPLETED
**Date:** 2026-03-04

## Goal
Complete the transition to the v2.0 architecture by addressing remaining security risks, polishing the Persistence/Sync UX, and implementing advanced payoff logic for fixed-term debts.

## Requirements

### Security & Infrastructure (SEC)
- [x] **SEC-01: UUID Fallback**: Implement a robust fallback for `crypto.randomUUID()` to prevent initialization failures in non-secure (non-HTTPS/localhost) environments.
  - *Outcome:* Verified in `src/utils/security.js`. Used in schema v12+ migration and repository.

### Persistence & Sync UX (SYNC)
- [x] **SYNC-01: Banner Logic**: Update the persistence warning banner to appear *only* if the browser storage is not persistent **and** no local file sync is active.
  - *Outcome:* Verified in `src/ui/file-sync.js`.
- [x] **SYNC-02: Action Renaming**: Rename "Reset Persistence" to "Disconnect File" in the toolbar for clarity.
  - *Outcome:* Verified in `src/ui/file-sync.js`.
- [x] **SYNC-03: Header Hints**: Ensure header hints dynamically update to reflect the active sync filename or "Local/IndexedDB" status.
  - *Outcome:* Verified in `src/ui/file-sync.js`.

### Advanced Debt & Payoff (DEBT)
- [x] **DEBT-01: Fixed-term Logic**: Enhance the Payoff Planner to support fixed-term debt logic, including early repayment fees and interest-only vs. repayment distinctions.
  - *Outcome:* Verified in `src/utils/finance.js` (`simulateLoanPayoff`) and `src/ui/payoff.js`.

### Power-User Utilities (UTIL)
- [x] **UTIL-01: Manual Recurrence Trigger**: Add a manual "Trigger Recurrence" button to the Expenses UI.
  - *Outcome:* Verified in `index.html` and `src/ui/expenses.js`.
- [x] **UTIL-02: Balance Consolidation**: Consolidate "Start Month" and "Opening Balance" into a single "Balance Configuration" block in the Settings tab.
  - *Outcome:* Verified in `index.html` (Settings tab) and `src/app.js`.

### UI Cleanup (CLEAN)
- [x] **CLEAN-01: Legacy Removal**: Remove the redundant "Import Bank Statement" button from the Income tab.
  - *Outcome:* Verified in `index.html`.

## Success Criteria Verification
1. [x] **Reliability**: App initializes without error on all supported browsers (including non-HTTPS fallbacks).
2. [x] **Clarity**: The persistence banner correctly hides when a local file is connected.
3. [x] **Accuracy**: The Payoff Planner accurately calculates "Months to Clear" for loans with early repayment fees.
4. [x] **Parity**: Legacy v1.x UI elements are fully removed.
