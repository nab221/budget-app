# Milestone v2.1 Requirements: Advanced Refinements & Security

## Goal
Complete the transition to the v2.0 architecture by addressing remaining security risks, polishing the Persistence/Sync UX, and implementing advanced payoff logic for fixed-term debts.

## Requirements

### Security & Infrastructure (SEC)
- **SEC-01**: Implement a robust fallback for `crypto.randomUUID()` in `src/db/schema.js` to prevent initialization failures in non-secure (non-HTTPS/localhost) environments.

### Persistence & Sync UX (SYNC)
- **SYNC-01**: Update the persistence warning banner to appear *only* if the browser storage is not persistent **and** no local file sync is active (UI-01 parity).
- **SYNC-02**: Rename "Reset Persistence" to "Disconnect File" in the toolbar for clarity (UI-04 parity).
- **SYNC-03**: Ensure header hints dynamically update to reflect the active sync filename or "Local/IndexedDB" status (UI-05 parity).

### Advanced Debt & Payoff (DEBT)
- **DEBT-01**: Enhance the Payoff Planner to support fixed-term debt logic, including early repayment fees and interest-only vs. repayment distinctions for Mortgages (DEBT-10 parity).

### Power-User Utilities (UTIL)
- **UTIL-01**: Add a manual "Trigger Recurrence" button to the Expenses UI to allow users to force-generate pending instances.
- **UTIL-02**: Consolidate "Start Month" and "Opening Balance" into a single "Balance Configuration" block in the Settings tab.

### UI Cleanup (CLEAN)
- **CLEAN-01**: Remove the redundant "Import Bank Statement" button from the Income tab, as statement imports are now handled via the Debts tab or Settings (UI-07 parity).

## Success Criteria
1. The app initializes without error on all supported browsers (including non-HTTPS fallbacks).
2. The persistence banner correctly hides when a local file is connected.
3. The Payoff Planner accurately calculates "Months to Clear" for loans with early repayment fees.
4. Legacy v1.x UI elements are fully removed.
