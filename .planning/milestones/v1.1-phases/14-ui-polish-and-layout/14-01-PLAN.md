# Phase 14-01: CSS and Layout Foundation

This phase focuses on the structural and stylistic changes required to address visual density and prepare for the modal-based entry system.

## Goals
- Increase visual "breathing room" across the app.
- Unified dashboard balance card styling.
- Utility for dynamic font scaling and short currency notation.

## Tasks
1. **CSS Refinements**:
   - Update `css/main.css` for increased padding in summary cards and tables.
   - Ensure table cells wrap text correctly (`white-space: normal`, `word-break: break-word`).
   - Add specific styles for the dashboard "balance banner" cards.
2. **Currency Utils**:
   - Add `formatGBPShort` to `src/utils/currency.js` (e.g., £10.5k).
3. **Generalize Modals**:
   - Extract modal management logic from `src/ui/templates.js` to `src/ui/render.js`.
   - Update `index.html` to prepare for modal triggers.

## Verification
- [ ] Summary cards show 16px horizontal padding.
- [ ] Table rows are taller and text wraps.
- [ ] `formatGBPShort` correctly formats large values.
- [ ] Modal can be opened/closed via the new `render.js` utility.
