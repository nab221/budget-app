# Requirements: Budget App v1.2 (Daily Cash Flow Engine)

**Milestone Goal:** Predict daily balances 90 days forward, handling UK bank holidays and weekends, with auto-generation of expected income.

## v1.2 Requirements

### Schema & Data Infrastructure (SCHEMA-01)
- [x] **SCHEMA-01.1**: Implement Schema v10 including `dailyBalanceSnapshots`, `expectedIncome`, and `bankHolidayOverrides`.
- [x] **SCHEMA-01.2**: Implement robust migrations for Schema v10.
- [x] **SCHEMA-01.3**: Add repositories for new tables in `src/db/repository.js`.
- [x] **SCHEMA-01.4**: UK Bank Holiday handling via `gov.uk` API integration.
- [x] **SCHEMA-01.5**: Offline caching for UK Bank Holiday data to ensure engine works without internet.

### Forecast Engine (FORC-01)
- [x] **FORC-01.1**: Implement 90-day forecast engine in `src/utils/cashflow.js` (opening + income - expenses = closing).
- [x] **FORC-01.2**: Implement logic to move expenses falling on weekends or bank holidays to the next working day.
- [x] **FORC-01.3**: Day-by-day iteration for 90 days to generate balance snapshots.

### Expected Income Engine (INC-01)
- [x] **INC-01.1**: Auto-generate expected income entries from historical transaction patterns.
- [x] **INC-01.2**: Provide UI for managing/overriding auto-generated expected income in `src/ui/expected-income.js`.

### Cash Flow UI & Dashboard (UI-01)
- [x] **UI-01.1**: New "Cash Flow Planner" tab to view 90-day daily breakdown.
- [x] **UI-01.2**: Add 90-day forecast chart to the main Dashboard.
- [x] **UI-01.3**: Implement "Critical Date Warnings" for days where balance is predicted to fall below zero or a threshold.
- [x] **UI-01.4**: Update `dashboard.js` and `charts.js` to integrate the new forecast data.
