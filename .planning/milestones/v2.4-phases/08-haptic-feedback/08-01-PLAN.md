# Plan: Phase 8-01 - Haptic Feedback Infrastructure

<objective>
Establish the haptic feedback utility, persistence layer, and settings UI.
</objective>

<context>
@src/utils/storage.js
@index.html
@src/app.js
</context>

<tasks>
<task type="auto">
  <name>Create Haptic Utility</name>
  <files>src/utils/haptics.js</files>
  <action>
    Implement a utility module `src/utils/haptics.js` that exports:
    - `HAPTIC_PATTERNS`: { tap: [10], success: [30, 20, 30], delete: [40, 15, 25, 15, 15], error: [60, 40, 60] }.
    - `triggerHaptic(type)`: 
      - Checks `localStorage.getItem('budget_haptics_enabled')` (default 'true').
      - Uses a `lastPulseTime` map per type to enforce a 300ms debounce.
      - Wraps `navigator.vibrate` in a try-catch and checks `if ('vibrate' in navigator)`.
    - `alertWithHaptic(message, type = 'error')`: 
      - Calls `triggerHaptic(type)` synchronously.
      - Then calls `window.alert(message)`.
  </action>
  <verify>
    1. Check file exists and exports required symbols.
    2. Verification of debounce: Add `console.log` inside `triggerHaptic`. Call `triggerHaptic('tap')` 5 times rapidly in the console; confirm only the first one triggers a log/vibration within any 300ms window.
  </verify>
  <done>Utility is functional, safe for all browsers, and honors settings with correct rhythmic patterns.</done>
</task>

<task type="auto">
  <name>Configure Storage and Settings UI</name>
  <files>src/utils/storage.js, index.html, src/app.js</files>
  <action>
    - In `src/utils/storage.js`, export `HAPTICS_ENABLED_KEY = 'budget_haptics_enabled'`.
    - In `index.html`, add a "Preferences" section header and a checkbox for "Haptic Feedback" in the Settings tab (after Category Management or Balance Start).
    - In `src/app.js`:
      - Initialize the checkbox state from localStorage (default true).
      - Add a 'change' listener to the checkbox to save state.
      - Toggling to 'Enabled' must call `triggerHaptic('tap')`.
      - Ensure state is synced to the DOM when switching to the 'settings' tab.
  </action>
  <verify>Settings checkbox appears, persists value to localStorage, and triggers a pulse when checked. State is correct when re-entering the tab.</verify>
  <done>User can enable/disable haptics via the UI.</done>
</task>
</tasks>
