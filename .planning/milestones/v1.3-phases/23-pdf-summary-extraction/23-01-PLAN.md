<feature>
  <name>PDF Statement Summary Extraction</name>
  <files>src/utils/pdf-parser.js, src/utils/pdf-parser.test.js</files>
  <behavior>
    The function `extractStatementSummary(rows)` should:
    - Join all text into a single string for label-based searching.
    - Extract Opening Balance, New (Closing) Balance, Minimum Payment Due, Payment Due Date, and Statement Date.
    - Handle labels from Barclays, HSBC, Lloyds, Santander, and NatWest (per RESEARCH.md).
    - Convert all currency amounts to pence using `toPence()`.
    - Normalize dates to ISO format (YYYY-MM-DD) using `date-fns`.
    - Return a clean object with extracted fields.
    
    Cases:
    - Barclays: "New Balance £1,234.56" -> 123456
    - HSBC: "Minimum Payment Due £25.00" -> 2500
    - Lloyds: "Payment Due Date 14 Aug 2025" -> "2025-08-14"
    - NatWest: "Opening Balance £0.00" -> 0
  </behavior>
  <implementation>
    1. Join rows: `const text = rows.map(r => r.map(i => i.text).join(' ')).join(' ');`
    2. Define regex patterns from RESEARCH.md for each field.
    3. Use `text.match(regex)` to extract strings.
    4. Clean extracted currency strings (remove £, commas) before calling `toPence`.
    5. Use `date-fns` (e.g., `parse`) to handle various bank date formats (DD/MM/YYYY, DD MMM YYYY).
  </implementation>
</feature>
