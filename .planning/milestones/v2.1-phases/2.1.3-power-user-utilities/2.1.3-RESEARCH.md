**Researched:** 2026-03-04

## Summary
This phase focuses on exposing advanced manual controls to the user. UTIL-01 adds a manual "Trigger Recurrence" button to the Expenses UI, bridging the gap for users who want to force-generate upcoming transactions (e.g., when planning ahead). UTIL-02 consolidates the balance start configuration in the Settings tab, which is already partially structured but needs a formal "Power-User" refinement.

**Primary recommendation:** Use the existing `templateUI.manualTrigger()` logic for the recurrence button and ensure the Balance Configuration block in Settings correctly handles the background recalculation chain.

## Standard Stack
- **Framework**: Vanilla JS / ES Modules.
- **Persistence**: IndexedDB (via Dexie.js).
- **Icons**: Emoji-based or CSS-styled (as per existing patterns).

## Architecture Patterns

### UTIL-01: Recurrence Trigger
- **Placement**: `index.html` > `#tab-content` > `[data-panel="expenses"]` > toolbar area.
- **Implementation**:
  ```html
  <button id="triggerRecurrenceBtn" class="ghost sm">🔁 Trigger Recurrence</button>
  ```
- **Binding**: In `src/ui/expenses.js` or `src/app.js`:
  ```javascript
  document.getElementById('triggerRecurrenceBtn').onclick = () => window.templateUI.manualTrigger();
  ```

### UTIL-02: Balance Consolidation
- **State**: Currently uses `localStorage` keys `balance_start_date` and `balance_opening_amount`.
- **Logic**: Needs to trigger `triggerBalanceRecalc()` after saving to ensure the entire history is updated.

## Don't Hand-Roll
- **Recurrence Logic**: Do NOT rewrite the recurrence generation. Use `RecurrenceManager.checkAndGenerate()` from `src/utils/recurrence.js`.
- **Recalculation**: Use `triggerBalanceRecalc()` from `src/db/repository.js`.

## Common Pitfalls
- **Double Clicks**: Ensure the trigger button is disabled or shows a loading state during execution to prevent multiple bulk-add operations.
- **Balance Drift**: Consolidating the start month and opening balance must be done atomically in the logic to prevent partial recalculations with old data.

## Code Examples

### Manual Trigger Integration
```javascript
// src/ui/expenses.js or src/app.js
const triggerBtn = document.getElementById('triggerRecurrenceBtn');
if (triggerBtn) {
  triggerBtn.onclick = async () => {
    triggerBtn.disabled = true;
    await window.templateUI.manualTrigger();
    triggerBtn.disabled = false;
  };
}
```
