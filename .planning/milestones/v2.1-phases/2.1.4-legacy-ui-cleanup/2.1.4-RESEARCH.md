# Phase 2.1.4: Legacy UI Cleanup & Final Parity - Research

**Researched:** 2026-03-04
**Domain:** UI Cleanup / Tech Debt
**Confidence:** HIGH

## Summary
Phase 2.1.4 focuses on removing the last remnants of v1.x UI patterns that contradict the v2.0 "Ledger-first" vision. The primary target is the "Import Bank Statement" button on the Income tab, which has been superseded by the inline PDF import functionality within the Debts tab's statement ledger. Additionally, an audit revealed that while some v1.x features (like Cash Flow) have been removed from the tabs, their underlying code and some orphaned DOM elements/references remain.

**Primary recommendation:** Remove the orphaned button from the Income tab and perform a targeted cleanup of `app.js` and `pdf-import.js` to ensure they point only to the new active import triggers.

## User Constraints
- **Cleanup Requirement**: FORMAL REMOVAL of "Import Bank Statement" button on Income tab.
- **Success Criteria**: No broken references to the old `pdfImportFile` ID.

## Standard Stack
- Vanilla JS / DOM API

## Architecture Patterns
### Recommended Cleanup Workflow
1. Identify orphaned DOM elements in `index.html`.
2. Trace event listeners in `app.js` or specific UI modules.
3. Remove unused initialization calls.
4. Verify that the "new" path (Debts -> Statement -> Import PDF) remains fully functional.

## Don't Hand-Roll
- **DOM Removal:** Use standard `element.remove()` or manual HTML deletion.

## Common Pitfalls
### Pitfall 1: Broken References
**What goes wrong:** Removing a button or input that is referenced by code in `pdf-import.js` (e.g., `document.getElementById('pdfImportFile')`) can cause runtime errors during the *active* import flow (e.g., when clicking "Upload Another" in the success modal).
**How to avoid:** Ensure the hidden file input `id="stmtPdfFile"` (in the Debts tab) is the single source of truth for PDF selection and update all references to point to it.

## Code Examples
### Removing the Redundant Button
In `index.html`, remove:
```html
<button class="ghost sm" onclick="document.getElementById('pdfImportFile').click()">📄 Import Bank Statement</button>
```

### Updating Success Modal
In `src/ui/pdf-import.js`, update the "Upload Another" button to reference the active input:
```javascript
<button class="ghost" onclick="document.getElementById('stmtPdfFile').click()">Upload Another</button>
```
