# Context: Phase 2.1.2 - Advanced Debt & Payoff Logic

## Objective
Implement high-fidelity payoff calculations for fixed-term debts (loans/mortgages) including interest-only vs. repayment distinctions and full test coverage for the simulation logic.

## Requirements
- **DEBT-10** (extension): Enhance Payoff Planner to support fixed-term debt logic.
- **DEBT-11**: Add interest-only vs. repayment distinctions for Mortgages.
- **DEBT-12**: Ensure early repayment fees (ERC) are correctly handled (partially implemented, need verification).
- **DEBT-13**: Add comprehensive tests for `simulateLoanPayoff`.

## Decisions (Locked)
- **Interest-Only Toggle**: Provide a simple checkbox in the loan/mortgage form.
- **ERC Allowance**: Standard 10% annual allowance on original principal applies for all UK loans/mortgages.
- **ERC Charging**: If an ERC fee is triggered, it should be added back into the balance (reducing the principal reduction of the payment).
- **Test-Driven**: Create tests for all edge cases first.

## Claude's Discretion
- **UI Labels**: Use "Interest-Only" and "Repayment" as clear labels.
- **ERC Display**: Show "ERC Charged" in the history table if a fee was applied in a given month.

## Current State
- `src/db/schema.js` is at Version 14.
- `src/utils/finance.js` has `simulateLoanPayoff` with basic ERC logic.
- `src/ui/debts.js` and `src/ui/payoff.js` are functional for basic loan tracking.
