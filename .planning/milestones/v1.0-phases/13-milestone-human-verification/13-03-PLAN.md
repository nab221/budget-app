  <name>Task 1: Implement _showFieldError, _clearFieldErrors, and _saveDebt</name>
  <files>src/ui/debts.js</files>
  <action>
    Add three new methods to the debtUI object. Place them after _onTypeChange() and before
    _buildFormHTML().

    --- _clearFieldErrors() ---
    Synchronous. Removes all elements matching '.field-error' from the document:
      document.querySelectorAll('.field-error').forEach(el => el.remove());

    --- _showFieldError(fieldId, message) ---
    Synchronous. Finds the element by fieldId, creates a span, inserts it afterend:
      const field = document.getElementById(fieldId);
      if (!field) return;
      const span = document.createElement('span');
      span.className = 'field-error';
      span.textContent = message;
      field.insertAdjacentElement('afterend', span);

    --- _saveDebt() (async) ---
    This is the single save entry point for both Add and Edit:

    1. Call this._clearFieldErrors() first.
    2. Read name = document.getElementById(FIELD_IDS.name)?.value.trim() || ''.
    3. Read type = document.getElementById(FIELD_IDS.type)?.value.
    4. If name is empty: call this._showFieldError(FIELD_IDS.name, 'Name is required') and return.
    5. Build payload by type:

       credit-card:
         apr = parseFloat(getElementById(FIELD_IDS.ccApr).value) || 0
         currentBalance = parseFloat(getElementById(FIELD_IDS.ccBalance).value) || 0
         creditLimit = parseFloat(getElementById(FIELD_IDS.ccLimit).value) || 0
         minPayment = parseFloat(getElementById(FIELD_IDS.ccMinPayment).value) || 0
         promoEnd = getElementById(FIELD_IDS.ccPromoEnd).value
         postApr = parseFloat(getElementById(FIELD_IDS.ccPostApr).value)
         payload = { name, debtType: type, apr, currentBalance, creditLimit, minPayment,
                     promoEndDate: promoEnd || null, postPromoApr: isNaN(postApr) ? apr : postApr }

       mortgage:
         propertyValue = parseFloat(getElementById(FIELD_IDS.mortgagePropertyValue).value) || 0
         currentBalance = parseFloat(getElementById(FIELD_IDS.mortgageBalance).value) || 0
         termMonths = parseInt(getElementById(FIELD_IDS.mortgageTerm).value) || 0
         interestRate = parseFloat(getElementById(FIELD_IDS.mortgageRate).value) || 0
         earlyRepaymentFee = parseFloat(getElementById(FIELD_IDS.mortgageErc).value) || 0
         payload = { name, debtType: type, propertyValue, currentBalance, termMonths,
                     interestRate, apr: interestRate, earlyRepaymentFee }

       personal-loan:
         originalPrincipal = parseFloat(getElementById(FIELD_IDS.loanOriginal).value) || 0
         currentBalance = parseFloat(getElementById(FIELD_IDS.loanBalance).value) || 0
         termMonths = parseInt(getElementById(FIELD_IDS.loanTerm).value) || 0
         interestRate = parseFloat(getElementById(FIELD_IDS.loanRate).value) || 0
         payload = { name, debtType: type, originalPrincipal, currentBalance, termMonths,
                     interestRate, apr: interestRate }

       other (fallback):
         currentBalance = parseFloat(getElementById(FIELD_IDS.otherBalance).value) || 0
         payload = { name, debtType: type, currentBalance }

    6. try/catch:
       if (this.editingId): await debtRepository.update(this.editingId, payload)
       else: await debtRepository.add(payload)
       triggerHaptic('success')
       this._closeDebtModal()
       await this.render()
       window.app?.renderAll()
    On catch: this._showFieldError(FIELD_IDS.name, 'Failed to save. Please try again.')

    IMPORTANT — Do NOT call or reference handleSaveDebt(), renderDebtForm(), or
    toggleDebtForm() — those belong to the old inline form (removed in Phase 14).

    NOTE on minPayment vs fixedMonthlyPayment: credit-card reads ccMinPayment → payload key
    is 'minPayment' (NOT in pence list, stored as plain GBP float per RESEARCH.md pitfall 2).
    propertyValue is also NOT in the pence list — pass as plain float.
  </action>
