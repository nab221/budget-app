# Milestone v2.3 Audit: Advanced Analytics & Mobile Polish

**Date:** 2026-03-06
**Status:** GAPS IDENTIFIED

## Overview
Milestone v2.3 delivered core analytics, reconciliation, and mobile UI improvements. However, post-implementation review has identified several regressions and UX inconsistencies.

## Identified Gaps

### 1. Privacy Mode Leaks (DASH-01)
- **Issue**: Privacy blur is not applied to components in the Dashboard tab (Summary Cards, Savings Rate KPI).
- **Issue**: Debts and balances are fully visible in the Payoff Planner tab.
- **Requirement**: ALL sensitive monetary values must respect the `privacy-enabled` state.

### 2. Dashboard UI Redundancy (DASH-02)
- **Issue**: Duplicate "Dashboard" title above 'Rolling Financial Overview'.
- **Fix**: Remove the secondary title as the tab name is sufficient.

### 3. Graph Data Insufficiency (DASH-03)
- **Issue**: 'Rolling Financial Overview' chart only shows the balance line.
- **Enhancement**: Add Income and Expenses lines to the daily rolling chart for better context.

### 4. Forecast Inconsistency (FORC-01)
- **Issue**: Balance values differ between the Graph and the 'Detailed Forecast' table.
- **Issue**: Inconsistent lookahead horizons (Graph: 30 days, Table: 90 days).
- **Target**: Align both to use the same calculation engine and a unified 45-day horizon.

### 5. Analytics Layout Inconsistency (UX-01)
- **Issue**: 'Spending Analytics' section is currently sandwiched between the graph and the navigation controls.
- **Issue**: Navigation controls affect analytics data but are placed below them.
- **Fix**: Reorder the dashboard sections so that navigation/period selectors are above the analytics/summary panels they control, or move analytics to the bottom.

## Prioritization
1. **Critical**: Privacy Mode Leaks (Security/Privacy concern).
2. **High**: Forecast Inconsistency (Data integrity trust).
3. **Medium**: Dashboard Layout & Graph lines (UX/Utility).
4. **Low**: UI Redundancy (Polish).
