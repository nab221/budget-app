# Requirements Archive: v1.0 — Budget App

**Shipped:** 2026-03-01
**Final Status:** 91 satisfied, 1 deferred

## Outcomes Summary

- **Validated:** Core CRUD, debt simulations, PWA capability, PDF parsing, cloud sync, and balance carry-forward logic were all confirmed through browser UAT.
- **Adjusted:** The "Subscriptions" tab (SUB-01–04) was merged into the "Recurrent Expenses" view during Phase 8 to simplify the UX.
- **Deferred:** PWA-03 (iOS Safari "Add to Home Screen" banner) was formally deferred to future maintenance, as Chrome/Android and Windows/Edge installation flows are sufficient for initial launch.
